1

화면 구성 및 3분할 구조 완벽 이해

OpenStat Studio는 자모비(jamovi)의 직관적인 디자인을 계승하여 데이터 스프레드시트, 분석 옵션 창, 결과 문서 창이 한 화면에 동시에 펼쳐지는 반응형 워크스페이스입니다.

핵심 영역 화면의 3개 주요 구역
  1. [좌측 영역] 스프레드시트 & 변수 보기: 엑셀처럼 표 형태로 데이터를 확인하고, 상단 탭에서 변수 보기를 누르면 변수별 척도(명목/순서/연속)와 결측치를 한눈에 검토할 수 있습니다.
  2. [중앙 영역] 분석 옵션 패널: 분석 메뉴를 클릭했을 때 나타나는 설정 창입니다. 왼쪽의 변수 목록을 오른쪽 종속변수/집단변수 상자로 이동시키고 가설검정 옵션을 체크합니다.
  3. [우측 영역] APA 결과 시트 (Results): 옵션을 클릭하는 즉시 학술 논문 규격(APA 7th)의 통계 표와 고해상도 그래프가 실시간으로 자동 렌더링됩니다.
💡 언어 선택 팁: 상단 우측의 한국어 / English 버튼을 누르면 언제든지 모든 메뉴와 통계 용어가 한글/영문으로 1초 만에 전환됩니다. (기본값: 한국어)
2

엑셀 / CSV / jamovi 데이터 불러오기

연구자의 엑셀(`.xlsx`), 텍스트(`.csv`), 또는 jamovi 바이너리 컨테이너(`.omv`) 파일을 1클릭으로 불러옵니다.

1단계 파일 메뉴 열기

화면 맨 왼쪽 상단의 메뉴 버튼 ☰ 을 클릭합니다.

2단계 내 파일 선택 또는 샘플 데이터 선택

• 내 컴퓨터 파일 열기: [열기...] 버튼을 눌러 내 엑셀/CSV 파일을 선택합니다.
• 실습용 데이터 열기: [샘플 데이터 라이브러리] 를 누르고 ToothGrowth.csv(비타민C 투여 치아성장 실험 데이터)를 클릭합니다.

3단계 변수 척도(측정 수준) 확인 및 변경

상단 탭에서 [변수(Variables)] 를 클릭합니다. 각 변수의 열 머리글 아이콘을 클릭하여 척도를 손쉽게 변경할 수 있습니다:

아이콘측정 척도설명 및 적용 대상
📊 자 모양연속형 (Continuous)신장, 체중, 점수, 소득 등 연속적인 수치형 데이터 (T-검정, ANOVA의 종속변수)
📶 계단 모양순서형 (Ordinal)만족도(1~5점 리커트 척도), 학력 수준 등 순서가 있는 데이터
🟢 세 원 모양명목형 (Nominal)성별(남/여), 투여방식(OJ/VC), 실험집단(A/B/C) 등 순서 없는 범주형 데이터
🆔 ID 카드ID 변수참여자 번호, 고유 식별자 (통계 분석 계산에서 자동 제외)
3

두 집단 평균 비교: 독립표본 T-검정 (Click-to-Click)

실습 예시: ToothGrowth.csv 데이터에서 두 가지 비타민C 투여 방식(OJ: 오렌지주스 vs VC: 아스코르브산)에 따라 기니피그 치아 길이(len)의 평균에 통계적으로 유의한 차이가 있는지 검정합니다.

Step 1 T-검정 메뉴 클릭

상단 [분석(Analyses)] 탭 → [T-검정 ▾] 클릭 → [독립표본 T-검정 (Independent Samples T-Test)] 을 클릭합니다.

Step 2 변수를 상자로 투입하기

1. 왼쪽 변수 목록에서 len(치아 길이)을 마우스로 클릭하고, [종속변수] 옆의 ▶ 화살표 버튼을 클릭합니다.
2. 왼쪽 변수 목록에서 supp(투여 방식 OJ/VC)를 클릭하고, [집단변수] 옆의 ▶ 화살표 버튼을 클릭합니다.

옵션 패널: 독립표본 T-검정 (Independent Samples T-Test)
변수 목록
• len
• supp
• dose
▶

▶
종속변수 (Dependent)
[ len ]

집단변수 (Grouping)
[ supp ]
Step 3 필수 학술 옵션 체크

옵션 패널 하단에서 다음 항목들의 체크박스를 선택합니다:
• ☑ Student's t & ☑ Welch's t (등분산 가정이 위배되었을 때 안전하게 사용)
• ☑ 등분산성 검정 (Homogeneity test - Levene's)
• ☑ 효과크기 (Effect size - Cohen's d)
• ☑ 기술통계 도표 (Descriptives Plot - 집단별 평균 및 95% 신뢰구간)

Step 4 결과 확인 및 APA 해석

우측 결과창에 즉시 APA 3선 통계표가 나타납니다:
• 통계량: $t(58) = 1.915, p = .060$
• 해석: 유의확률 $p = 0.060$으로 유의수준 5%($\alpha=.05$) 기준에서 두 투여방식 간에 통계적으로 유의미한 차이가 나타나지 않았습니다.

4

세 집단 이상 비교: 일원배치 분산분석 & 5종 사후검정

실습 예시: 비타민C 투여 용량(dose: 0.5mg, 1.0mg, 2.0mg의 3개 집단)에 따라 치아 성장 길이(len)에 유의미한 차이가 있는지 검정하고 사후검정(Post-Hoc)을 수행합니다.

Step 1 분산분석 메뉴 선택

상단 [분석] 탭 → [분산분석(ANOVA) ▾] → [일원배치 분산분석 (One-Way ANOVA)] 클릭!

Step 2 변수 투입

• [종속변수] 상자에 len 투입
• [집단변수] 상자에 dose 투입

Step 3 사후검정(Post-Hoc) 방법 선택

집단 간 분산이 같지 않은 경우(등분산 기각)를 대비하여 사후검정 드롭다운에서 Games-Howell 을 선택합니다. (등분산이 만족되면 Tukey HSD 선택).

Step 4 분석 결과 확인

• One-Way ANOVA 표: $F(2, 57) = 67.42, p < .001, \eta^2 = 0.703$
• 사후검정 표: 0.5mg vs 1.0mg ($p < .001$), 1.0mg vs 2.0mg ($p < .001$), 0.5mg vs 2.0mg ($p < .001$) 모두 유의미한 차이가 확인되어, 투여 용량이 증가할수록 치아 길이가 뚜렷하게 길어짐을 실증합니다.

5

데이터 가공: 변수 계산, 재코딩, 행 필터링

Stata의 generate, recode, keep if, merge, reshape 명령을 마우스 버튼 클릭만으로 수행합니다.

기능 1 새 변수 수식 계산 (Compute)

1. [데이터] 탭에서 [계산(Compute)] 버튼을 누릅니다.
2. 상단에 계산 바가 열리면 새 변수명(예: len_sq)과 수식(예: len ** 2 또는 weight / (height/100)**2)을 입력하고 [계산]을 누릅니다.
3. 스프레드시트 맨 우측에 새 열이 즉시 생성됩니다!

기능 2 값 재코딩 및 범주화 (Recode)

1. [재코딩(Recode)] 버튼을 누릅니다.
2. 원본 변수로 dose를 선택하고, 새 변수명으로 dose_group을 적습니다.
3. 규칙 추가: 0.0 ~ 1.0 → 값 1 (라벨: 저용량), 1.1 ~ 2.0 → 값 2 (라벨: 고용량)을 설정한 후 [재코딩 실행]을 누르면 새로운 범주형 변수가 생성됩니다.

기능 3 조건에 맞는 데이터 필터링 (Filter)

1. [필터(Filter)] 버튼을 누릅니다.
2. 조건식 상자에 len >= 15 and supp == 'OJ' 와 같이 조건을 입력하고 [필터 적용]을 누릅니다.
3. 조건에 맞는 행만 추출되어 즉시 분석에 반영됩니다. 실수한 경우 [실행 취소(Undo)]를 누르면 1초 만에 원상 복구됩니다!

6

15종 독립형 학술 차트 빌더 & 디자인 스튜디오

통계 검정과 별개로, 데이터만으로 논문에 실을 수 있는 15가지 출판용 고해상도 그래프를 그립니다.

Step 1 차트 빌더 열기

상단 [그래프 및 디자인] 탭 클릭 → [차트 빌더(Graph Builder)] 또는 원하는 차트(Bar, Line, Raincloud, Scatter 등)를 클릭합니다.

Step 2 축 및 그룹 변수 지정

• X축: 범주 또는 기준 변수 (예: dose)
• Y축: 수치 변수 (예: len)
• 색상/그룹 분할: 집단 변수 (예: supp)

Step 3 학술 컬러 팔레트 & 테마 선택

상단의 [🎨 그래프 디자인] 버튼을 누르면 학술지에 맞춤화된 10종 컬러 팔레트를 고를 수 있습니다:
• kihasa: 한국보건사회연구원/공공기관 보고서 전용 스틸블루 & 웜 코랄
• apa_bw: 논문 심사용 순수 흑백(Grayscale) APA 패턴
• nature / lancet: 세계적 의과학 저널 스타일
• okabe_ito: 색각이상자(Colorblind) 배려 유니버설 팔레트

Step 4 무손실 벡터 SVG / 인쇄용 PDF 다운로드

결과창 그래프 상단의 [⬇ SVG] 또는 [⬇ PDF] 버튼을 누르면 인쇄 시 글자가 전혀 깨지지 않는 벡터 그래픽 파일이 즉시 다운로드됩니다.

Colab 및 외부 파이썬 환경에서 분석 재현하기

OpenStat Studio가 자동 생성한 파이썬 스크립트(live_session.py)는 유니버설 로더(Universal Loader)가 내장되어 있어, 독립 실행뿐만 아니라 Google Colab이나 Jupyter에서도 100% 동일하게 재현 실행됩니다.

파이썬 코드 3줄로 끝나는 파이썬 분석 예시
import openstat as ost

# 1. 세션 생성 및 데이터 불러오기
sess = ost.Session("sample_data/ToothGrowth.csv")

# 2. ANOVA 분석 및 학술 차트 디자인
res = sess.anova_oneway(deps="len", group="dose", descPlot=True)

# 3. 한글 보고서 및 엑셀로 한 번에 내보내기
res.export_results("reports/anova_report.hwpx")
res.export_results("reports/anova_report.xlsx")
10

GIS 공간분석 및 공간계량 회귀모형 (GeoDa & Stata spregress)

지리적 인접성이나 공간적 상호작용(예: 지역별 복지예산, 고령화율, 빈곤율 등)을 반영하는 공간자기상관 검정(Global Moran's I), 국소 공간 클러스터(LISA), 그리고 공간시차(SAR)·공간오차(SEM) 회귀모형을 마우스 클릭만으로 분석합니다.

1단계 리본 메뉴에서 공간분석 선택
화면 상단 리본 메뉴에서 [공간분석 (GIS) ▾] 버튼을 클릭하고 [공간회귀 모형 (Spatial Lag & Error / spregress)]을 선택합니다.
(첫 화면에서 🗺️ 서울 복지예산 GIS 데이터셋을 클릭하면 실측 좌표 데이터가 바로 준비됩니다.)
2단계 변수 슬롯 손으로 배치하기
좌측 변수 목록에서 마우스로 클릭하여 슬롯에 배치합니다:
• 종속변수 (Y): 분석 대상 변수 (예: welfare_expenditure)
• 위도 (Latitude): 지역 위도 좌표 (예: latitude)
• 경도 (Longitude): 지역 경도 좌표 (예: longitude)
• 설명변수 (Covariates): 독립변수들 (예: elderly_ratio, poverty_rate)
• 지역명/ID: 지자체 이름 (예: sgg_name)
3단계 공간 가중치 및 모형 선택 후 결과 확인
옵션 패널에서 가중치 행렬(k-NN / 역거리)과 모형(Spatial Lag / Spatial Error)을 선택하면 우측 결과 시트에 전역 모란 지수 검정표, 공간회귀 계수표, GeoDa 모란 산점도, 그리고 서울 25개 구 LISA 클러스터 지도가 실시간으로 렌더링됩니다!

대화형 SEM 빌더 (Stata SEM Builder / Amos 스타일 그래픽 모델러)

어려운 문법 코드를 외울 필요 없이, 타원(잠재변수)과 사각형(관측변수)을 캔버스에서 마우스로 직접 배치하고 화살표로 연결하여 구조방정식 모형을 설계하고 추정합니다.

1단계 SEM 빌더 캔버스 열기
상단 리본에서 [SEM / CFA]를 클릭한 뒤, 옵션 패널 상단의 초록색 [🎨 대화형 SEM 빌더 캔버스 열기] 버튼을 누릅니다. 대형 그래픽 캔버스 창이 열립니다.
2단계 잠재변수 생성 및 관측변수 추가
• 상단 도구함에서 [⭕ + 잠재변수]를 클릭하고 이름을 입력(예: F1_복지수요)하면 캔버스에 타원이 생성됩니다.
• 툴바의 [관측변수 추가] 칩(예: + elderly_ratio)을 클릭하면 사각형 노드가 캔버스에 추가됩니다.
• 원하는 위치로 마우스를 드래그하여 자유롭게 배치합니다.
3단계 화살표 연결 및 실시간 추정
• [➔ 경로 화살표] 도구를 선택한 후, 시작 노드(타원)를 클릭하고 대상 노드(사각형)를 클릭하면 측정 경로(=~) 또는 회귀 경로(~) 화살표가 즉시 연결됩니다.
• 하단 텍스트박스에 semopy / lavaan 표준 문법이 1초의 지연도 없이 자동 생성됩니다.
• 우측 상단의 [✓ 모델 적용 & 추정 실행 ▶]을 클릭하면 분석이 즉시 실행되고 적합도 지수(CFI, TLI, RMSEA)와 경로계수가 산출됩니다.

신택스 에디터 실시간 순차 기록 (Auto-Logging) & Stata 커맨드창

SPSS의 Paste 기능과 Stata의 Do-file Review를 완벽하게 결합했습니다. 마우스로 어떤 분석을 클릭하거나 변수를 옮기더라도 좌측 명령어 에디터에 실행 코드가 단계별 주석과 함께 순차적으로 누적 기록됩니다.

자동 기록 기본 세팅: 100% 자동 순차 기록
프로그램이 켜지면 [● 실시간 기록 ON]이 기본 활성화되어 있습니다. 메뉴를 클릭하거나 옵션을 바꿀 때마다:
# [단계 1: 데이터셋 로드] sess.load_data("Korea_Regional_Welfare_GIS.csv")
# [단계 2: 분석 실행] sess.spatial_regression(dep='welfare_expenditure', covs=['elderly_ratio'], lat='latitude', lon='longitude', model_type='lag')
형태로 순차 누적 기록되므로 나중에 💾 저장 버튼을 눌러 .do 또는 .py 파일로 한 번에 다운로드받아 연구 재현성을 입증할 수 있습니다.
실행 제어 선택 블록 실행 & Stata 한 줄 즉시 실행
• 블록 실행: 마우스로 특정 코드 구간을 드래그하고 ▶ 선택 실행 (Ctrl+Enter)을 누르면 해당 분석만 다시 수행됩니다.
• Stata 명령어 입력줄: 좌측 하단 명령어 > 입력창에 ttest len, by(supp) 또는 reg len supp dose를 타이핑하고 Enter를 치면 1초 만에 분석이 완료되어 결과 시트에 반영됩니다!
