화면 구성 및 3분할 구조 완벽 이해

OpenStat Studio는 자모비(jamovi)의 직관적인 디자인을 계승하여 데이터 스프레드시트, 분석 옵션 창, 결과 문서 창이 한 화면에 동시에 펼쳐지는 반응형 워크스페이스입니다.

핵심 영역 화면의 3개 주요 구역
  1. [좌측 영역] 스프레드시트 & 변수 보기: 엑셀처럼 표 형태로 데이터를 확인하고, 상단 탭에서 변수 보기를 누르면 변수별 척도(명목/순서/연속)와 결측치를 한눈에 검토할 수 있습니다.
  2. [중앙 영역] 분석 옵션 패널: 분석 메뉴를 클릭했을 때 나타나는 설정 창입니다. 왼쪽의 변수 목록을 오른쪽 종속변수/집단변수 상자로 이동시키고 가설검정 옵션을 체크합니다.
  3. [우측 영역] APA 결과 시트 (Results): 옵션을 클릭하는 즉시 학술 논문 규격(APA 7th)의 통계 표와 고해상도 그래프가 실시간으로 자동 렌더링됩니다.
💡 언어 선택 팁: 상단 우측의 한국어 / English 버튼을 누르면 언제든지 모든 메뉴와 통계 용어가 한글/영문으로 1초 만에 전환됩니다. (기본값: 한국어)

두 집단 평균 비교: 독립표본 T-검정 (Click-to-Click)

실습 예시: ToothGrowth.csv 데이터에서 두 가지 비타민C 투여 방식(OJ: 오렌지주스 vs VC: 아스코르브산)에 따라 기니피그 치아 길이(len)의 평균에 통계적으로 유의한 차이가 있는지 검정합니다.

Step 1 T-검정 메뉴 클릭

상단 [분석(Analyses)] 탭 → [T-검정 ▾] 클릭 → [독립표본 T-검정 (Independent Samples T-Test)] 을 클릭합니다.

Step 2 변수를 상자로 투입하기

1. 왼쪽 변수 목록에서 len(치아 길이)을 마우스로 클릭하고, [종속변수] 옆의 ▶ 화살표 버튼을 클릭합니다.
2. 왼쪽 변수 목록에서 supp(투여 방식 OJ/VC)를 클릭하고, [집단변수] 옆의 ▶ 화살표 버튼을 클릭합니다.

Step 3 필수 학술 옵션 체크

옵션 패널 하단에서 다음 항목들의 체크박스를 선택합니다:
• ☑ Student's t & ☑ Welch's t (등분산 가정이 위배되었을 때 안전하게 사용)
• ☑ 등분산성 검정 (Homogeneity test - Levene's)
• ☑ 효과크기 (Effect size - Cohen's d)
• ☑ 기술통계 도표 (Descriptives Plot - 집단별 평균 및 95% 신뢰구간)

Step 4 결과 확인 및 APA 해석

우측 결과창에 즉시 APA 3선 통계표가 나타납니다:
• 통계량: $t(58) = 1.915, p = .060$
• 해석: 유의확률 $p = 0.060$으로 유의수준 5%($\alpha=.05$) 기준에서 두 투여방식 간에 통계적으로 유의미한 차이가 나타나지 않았습니다.

4

세 집단 이상 비교: 일원배치 분산분석 & 5종 사후검정

실습 예시: 비타민C 투여 용량(dose: 0.5mg, 1.0mg, 2.0mg의 3개 집단)에 따라 치아 성장 길이(len)에 유의미한 차이가 있는지 검정하고 사후검정(Post-Hoc)을 수행합니다.

Step 1 분산분석 메뉴 선택

상단 [분석] 탭 → [분산분석(ANOVA) ▾] → [일원배치 분산분석 (One-Way ANOVA)] 클릭!

Step 2 변수 투입

• [종속변수] 상자에 len 투입
• [집단변수] 상자에 dose 투입

Step 3 사후검정(Post-Hoc) 방법 선택

집단 간 분산이 같지 않은 경우(등분산 기각)를 대비하여 사후검정 드롭다운에서 Games-Howell 을 선택합니다. (등분산이 만족되면 Tukey HSD 선택).

Step 4 분석 결과 확인

• One-Way ANOVA 표: $F(2, 57) = 67.42, p < .001, \eta^2 = 0.703$
• 사후검정 표: 0.5mg vs 1.0mg ($p < .001$), 1.0mg vs 2.0mg ($p < .001$), 0.5mg vs 2.0mg ($p < .001$) 모두 유의미한 차이가 확인되어, 투여 용량이 증가할수록 치아 길이가 뚜렷하게 길어짐을 실증합니다.

기능 5 자료 구조 변환 (reshape long · wide)
[구조 변환]을 누르면 「📐 자료 구조 변환」 창이 열립니다. Wide → Long은 stub(변수명 앞부분)과 식별 변수 i()를 지정하며, Long → Wide는 펼칠 변수, 식별 변수 i(), 시점 변수 j()를 지정합니다. 새 변수명은 stub + 구분자 + 시점값이며, 구분자 기본값은 없음(Stata와 같음, 예: bp + 1 → bp1)입니다.
조건처리
Wide → Long에서 i()가 행을 고유하게 식별하지 않음오류 (Stata: variable id does not uniquely identify the observations)
Long → Wide에서 (i, j) 조합 중복오류 (Stata: values of variable j not unique within i). 중복 행을 첫 값만 남기고 진행하지 않음
Long → Wide에서 펼치지 않는 변수가 i 안에서 변함오류 (Stata: variable not constant within i). 해당 변수를 펼칠 변수에 넣거나 삭제 후 실행
i() 또는 j()에 결측값오류. 결측 행 처리 후 실행

• 읽은 경계 파일은 프로그램 폴더의 workspace/boundaries/ 아래에 저장됩니다.

• 추천 연결: 데이터 변수와 경계 속성의 모든 조합 가운데 데이터 지역이 경계에서 발견되는 비율이 높은 조합을 '데이터 변수 ↔ 경계 속성 · 일치 수/지역 수 (비율)' 단추로 제시합니다. 단추를 누르면 아래 선택 칸이 채워집니다.
• [데이터의 지역 코드 변수], [경계 파일의 연결 속성](값이 모두 다른 속성에는 '(고유)' 표시), [지역명 변수 (지도 표기)]를 확인하면 "예상 일치: 데이터 지역 N곳 중 M곳" 문구가 표시됩니다.
• [▶ 현재 데이터에 연결]을 누르면 "연결 완료 — 데이터 지역 N곳 중 M곳 일치"와 함께 경계에서 찾지 못한 데이터 지역(공간분석에서 제외), 자료가 없는 경계 도형, 같은 코드의 도형이 여러 개인 지역(하나로 합쳐 사용)이 예시와 함께 표시되고, 미리보기에서 연결된 지역은 파란색, 자료가 없는 지역은 회색으로 표시됩니다.
⚠ 지역 코드 비교 규칙: 코드는 문자열로 비교하며 11010, 11010.0, 11010 은 같은 코드로 처리합니다. 앞자리 0은 유지되므로, 엑셀에서 숫자로 바뀌어 01010이 1010이 된 데이터는 경계의 01010과 일치하지 않습니다. 이러한 코드는 문자 형식으로 저장합니다. 일치하는 지역이 하나도 없으면 "일치하는 지역이 없음" 안내가 표시됩니다.

• 공간분석 옵션 패널 맨 위에 「🗺️ 지도 경계 연결됨 — 파일 이름」과 "데이터 '지역코드' ↔ 경계 'SIG_CD'" 형식의 연결 정보가 표시됩니다. [지역 식별자 (경계 연결 변수)]와 [지역명 (지도·표 표기, 선택)] 칸은 연결 정보로 자동 지정됩니다.
• [연결 해제 (좌표로 분석)]를 누르면 경계 연결이 해제되고 [x 좌표 (경도) — 경계 미연결 시], [y 좌표 (위도) — 경계 미연결 시] 칸이 나타납니다. 이름이 lon·longitude·경도·x, lat·latitude·위도·y인 변수는 자동 배정됩니다.

• 다른 데이터를 불러오면 경계 연결이 해제됩니다(예제 자료는 불러올 때 다시 자동 연결).

4단계 전역 Moran's I 읽기
「전역 공간자기상관 (Moran's I)」 표에는 변수, Moran's I, 기댓값 E[I](= −1/(N−1)), z, p(정규 근사), p(순열), 공간 패턴이 제시됩니다.
• Moran's I가 기댓값보다 크고 유의하면 양의 공간자기상관(유사한 값의 군집), 작고 유의하면 음의 공간자기상관(상이한 값의 인접)으로 판정합니다. '공간 패턴' 열은 정규 근사 p를 기준으로 판정합니다.
• p(정규 근사)는 무작위화 가정의 분산(Cliff & Ord)으로 계산한 값이고, p(순열)은 무작위 재배치로 얻은 I의 분포에서 관측값 쪽 꼬리에 해당하는 비율((해당 횟수 + 1) ÷ (순열 횟수 + 1))입니다. 순열 p의 최솟값은 1 ÷ (순열 횟수 + 1)입니다.
• 예제 횡단면 자료의 복지지출은 Moran's I = 0.197(z = 2.87, p = .004, 순열 p = .005)로 양의 공간자기상관을 보입니다.
5단계 LISA 군집과 다중검정 보정
국지 Moran's I(LISA)는 지역마다 자기 값과 이웃 값의 관계를 계산하고, 자기 값을 고정한 채 나머지 값을 이웃 자리에 무작위로 배치하는 조건부 순열로 유의확률을 구합니다. 유의한 지역은 다음 네 유형으로 분류됩니다.
군집 유형뜻지도 색
고-고 (High-High)높은 값의 지역이 높은 값의 이웃에 둘러싸인 군집빨강
저-저 (Low-Low)낮은 값의 지역이 낮은 값의 이웃에 둘러싸인 군집파랑
고-저 (High-Low)주변보다 값이 높은 이상 지역주황
저-고 (Low-High)주변보다 값이 낮은 이상 지역하늘색
• 「국지 공간자기상관(LISA) 군집 분포」 표는 유형별 지역 수, 「유의한 국지 군집 지역」 표는 지역·값·국지 Moran's I·p·군집 유형을 p가 작은 순으로 제시합니다.
• Moran 산점도: 가로축 = 표준화 변수, 세로축 = 공간시차(W·변수). 네 사분면이 고-고·저-저·고-저·저-고에 대응하며, 회귀선의 기울기는 행 표준화 W에서 Moran's I와 같습니다.
• 다중검정 보정: LISA는 지역 수만큼 검정을 동시에 수행하므로, 보정 없이 유의수준 0.05를 적용하면 공간 구조가 없어도 일부 지역이 유의하게 나타날 수 있습니다. FDR은 유의 판정 가운데 잘못된 판정의 기대 비율을 통제하고, Bonferroni는 p에 검정 수를 곱하는 가장 보수적인 방법입니다. 예제 횡단면 자료의 복지지출은 보정 없이 10곳(고-고 6곳 등)이 유의하고, FDR·Bonferroni 보정 후에는 유의한 지역이 없습니다. 보고서에는 보정 방법과 순열 횟수를 함께 제시합니다.
6단계 열점·냉점 (Getis–Ord Gi*) 읽기
Gi*는 자기 지역을 포함한 이웃 집합(가중치 1)의 값 합계가 전체 평균에서 기대되는 수준보다 큰지 작은지를 z 값으로 나타냅니다. z ≥ 2.576·1.96·1.645이면 열점 99%·95%·90%, z ≤ −2.576·−1.96·−1.645이면 냉점 99%·95%·90%로 분류하며, 다중검정 보정은 적용하지 않습니다. 이웃 집합만 사용하므로 가중행렬의 정규화 방식은 결과에 영향을 주지 않습니다. LISA가 군집과 이상 지역을 함께 구분하는 데 비해, Gi*는 높은 값 또는 낮은 값이 모인 지역의 위치를 나타냅니다.

7단계 계수 대신 직접·간접·총효과로 해석
ρ가 있는 모형(SAR·SDM·SAC)은 y = (I − ρW)−1(Xβ + WXθ + ε)로 다시 쓸 수 있으므로, 한 지역의 설명변수 변화는 이웃을 거쳐 다시 자기 지역으로 돌아오는 되먹임을 포함하여 모든 지역에 영향을 줍니다. 따라서 계수 β는 한계효과와 같지 않으며, 계수표 주석에도 "ρ가 있는 모형의 계수는 공간 되먹임 때문에 한계효과와 다름"이 기록됩니다. 「직접·간접·총효과 (LeSage–Pace)」 표는 효과를 다음과 같이 요약합니다(LeSage & Pace 2009).
• 직접효과: 자기 지역 설명변수 변화가 자기 지역 종속변수에 미치는 평균 효과(되먹임 포함)
• 간접효과(파급효과): 다른 지역 설명변수 변화가 해당 지역 종속변수에 미치는 평균 영향
• 총효과 = 직접효과 + 간접효과
ρ가 없는 SLX·SDEM에서 직접효과는 β, 간접효과는 θ(행 표준화 W일 때)입니다. 예제 자료의 SAR 모형(ρ = 0.397)에서 고령인구비율의 계수는 1.676이고, 직접효과 1.740, 간접효과 1.037, 총효과 2.777입니다. 표준오차는 델타 방법 또는 모수 분포 모의추출로 계산하며, 표 주석에 방법이 기록됩니다.
8단계 지도로 잔차 점검
「지도」 항목을 펼쳐 종속변수 주제도, 잔차 지도(파랑–빨강, 분위수 구분), 잔차 Moran 산점도를 확인합니다. 선택한 모형의 잔차에 공간 군집이 남아 있으면(잔차 Moran's I가 큼) 가중행렬이나 모형 명세를 다시 검토합니다.
💡 추정 결과 검증: 횡단면 SAR·SEM·SDM·SDEM의 계수와 로그우도는 PySAL spreg와 소수점 다섯째 자리까지 일치하고, EIM 표준오차, LM 검정, 잔차 Moran's I도 spreg와 일치합니다. OIM 표준오차는 계산 방식(관측정보행렬)이 달라 spreg의 값과 소폭 다릅니다. Stata와의 수치 비교는 수행하지 않았습니다.

6단계 지표 해석 (빈도·TF-IDF·c-TF-IDF)
• 빈도: 전체 문서에서 단어가 나온 총 횟수입니다.
• 문서 빈도·문서 비율: 단어가 한 번 이상 나온 문서의 수와 전체 문서 대비 비율입니다. 빈도가 높으면서 문서 비율이 낮은 단어는 일부 문서에 집중적으로 쓰인 단어입니다.
• TF-IDF 합계: 문서마다 '그 문서 안에서는 자주 쓰이고 다른 문서에서는 드물게 쓰이는 정도'(TF-IDF, 단어 빈도는 로그로 완화)를 계산하여 전체 문서에 걸쳐 더한 값입니다. 모든 문서에 고르게 쓰이는 일반 단어는 낮게, 특정 주제의 문서에 집중된 단어는 높게 나타납니다.
• c-TF-IDF (집단 기반 TF-IDF): 같은 집단의 문서를 하나의 문서로 합쳐 계산한 TF-IDF입니다. 해당 집단에서 자주 쓰이면서 다른 집단에서는 상대적으로 덜 쓰이는 단어일수록 값이 높습니다. 계산식은 (집단 내 단어 빈도 ÷ 집단의 전체 단어 수) × log(1 + 집단당 평균 단어 수 ÷ 전체 집단에서의 단어 빈도)입니다. 이 값은 집단 안에서 특징 단어의 순위를 정하는 상대 지표이며, 집단 간 차이의 통계적 유의성을 나타내지는 않습니다.
• 워드클라우드: 글자 크기는 선택한 기준 값(빈도 또는 TF-IDF)에 비례합니다. 글자의 색과 위치는 구분을 위한 배치로서 수치적 의미가 없으므로, 보고서에는 워드클라우드와 함께 키워드 표의 수치를 제시합니다.

지표뜻과 읽는 법
실루엣 계수각 문서가 자기 군집과 얼마나 가깝고 다른 군집과 얼마나 떨어져 있는지를 −1~1로 나타낸 값의 평균. 1에 가까울수록 군집이 잘 분리된 상태. 미분류 문서를 뺀 UMAP 축소 공간(UMAP 미적용 시 원래 벡터)에서 계산하므로, UMAP을 적용한 경우 원래 벡터 공간 기준보다 높게 산출되는 경향이 있어 설정 간 비교의 참고 지표로 활용
안정성 평균 ARI시드를 바꾼 재실행 결과와 원래 결과의 일치도. 1이면 같은 분류, 0이면 우연 수준의 일치. 값이 낮으면 군집 경계가 난수에 따라 달라지는 상태이므로 최소 군집 크기나 UMAP 이웃 수를 조정하여 비교

3단계 네트워크 설정
• 방향 네트워크 (출발 → 도착 구분) (기본 해제): 해제 상태에서는 A→B와 B→A를 같은 연결로 보고 가중치를 합산합니다. 선택하면 의뢰·자금 흐름처럼 방향이 있는 관계로 보고 그림에 화살표를 표시합니다. 방향 네트워크에서도 고유벡터 중심성과 묶음은 방향을 무시한 연결로 계산하며, 연결 중심성은 들어오는 연결과 나가는 연결을 합하여 계산합니다.
• 최소 가중치 (초과 연결만) (기본 0): 합산 가중치가 이 값보다 큰 연결만 사용합니다.
• 노드 크기·표 정렬 기준 (기본 가중 연결정도): 관계망 그림의 원 크기와 중심성 표의 정렬에 쓸 지표를 가중 연결정도 / 연결 중심성 / 매개 중심성 / 근접 중심성 / 고유벡터 중심성 / PageRank 가운데 선택합니다.
• 묶음·그림: Louvain 묶음(커뮤니티) (기본 선택), 묶음 해상도 (기본 1.0, 클수록 잘게), 배치 방식 (스프링 / Kamada-Kawai / 원형), 이름 표시 노드 수 (기본 30), 중심성 표 행 수 (기본 30, 0 = 전체), 관계망 그림 (기본 선택), 중심성 비교 막대도표 (기본 선택).

5단계 중심성 지표의 뜻
「노드 중심성」 표에는 순위, 노드, 6종 중심성, 묶음이 선택한 정렬 기준 순으로 제시됩니다. 중심성은 관계망 안에서 각 노드가 차지하는 위치의 중요도를 나타내는 지표입니다.
중심성뜻
연결 중심성 (degree)직접 연결된 노드 수를 (전체 노드 수 − 1)로 나눈 값. 관계의 폭
가중 연결정도 (strength)연결된 선의 가중치 합계. 관계의 양(예: 총 협력횟수)
매개 중심성 (betweenness)다른 노드 쌍을 잇는 최단 경로가 해당 노드를 지나는 비율. 집단 사이를 잇는 중개 위치
근접 중심성 (closeness)다른 노드까지의 평균 최단 거리의 역수. 관계망 전체에 짧은 경로로 닿을 수 있는 위치
고유벡터 중심성 (eigenvector)중심성이 높은 노드와 연결될수록 커지는 값. 영향력 있는 상대와의 연결 정도
PageRank연결을 따라 무작위로 이동할 때 해당 노드에 머무를 확률. 방향 네트워크에서는 들어오는 연결을 중시
매개 중심성과 근접 중심성의 거리는 '최대 가중치 ÷ 해당 연결의 가중치'로 계산합니다. 가중치가 큰 연결일수록 거리가 짧고, 가장 강한 연결의 거리는 1입니다.
